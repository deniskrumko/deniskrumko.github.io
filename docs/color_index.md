# Color Palette

This palette is used in the website design and photo editing.

| Color | HEX | Description |
| --- | --- | --- |
| Deep violet | `#2B0F54` | A dark purple with a rich, moody tone. |
| Berry magenta | `#AB1F65` | A deep pink with a strong purple undertone. |
| Coral pink | `#FF4F69` | A vivid, warm pink with a hint of red. |
| Blush white | `#FFF7F8` | A soft, near-white shade with a subtle pink tint. |
| Tangerine | `#FF8142` | A bright, warm orange. |
| Golden yellow | `#FFDA45` | A sunny yellow with a warm golden tone. |
| Royal blue | `#3368DC` | A saturated blue with a slightly violet undertone. |
| Bright cyan | `#49E7EC` | A vivid, cool cyan with a turquoise tint. |
